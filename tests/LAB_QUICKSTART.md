# Standalone training API

The demo/lab is no longer bundled into or managed by AchillesAPI. Obtain the **separate** `Independent-Vulnerable-API-Lab.zip` and start its `start.ps1` or `start.sh` from an independent terminal. Upload the lab's `openapi.json` into the dashboard exactly as for a client-provided OpenAPI file. See `docs/GUIA_DASHBOARD_INDIPENDENTE_V039_IT.md`.
